# Technical Projects

Selected projects demonstrating my experience with data engineering, analytics, machine learning, and applied technical problem-solving.

This repository includes selected work completed through my Data Engineering coursework and Capstone at Texas A&M, as well as research completed during my BIG-TCR summer internship at the McWilliams School of Biomedical Informatics at UTHealth Houston.

## Projects

### [ASL Alphabet Recognition](./asl-alphabet-recognition)
**Texas A&M University · Data Engineering Coursework**  
**Python · PyTorch · Computer Vision · ResNet-18 · Transfer Learning**

Developed and compared transfer-learning strategies for classifying static American Sign Language alphabet images. Evaluated four ResNet-18 training policies and examined generalization from benchmark data to a custom image set.

### [Electricity Generation Forecasting](./electricity-generation-forecasting)
**Texas A&M University · Data Engineering Coursework**  
**Python · R · Time Series Forecasting · ARIMA · LSTM**

Forecasted monthly U.S. electricity generation using statistical and deep-learning approaches. Compared seasonal ARIMA and LSTM models using a chronological test set and evaluated the tradeoffs between the approaches for a small, highly seasonal dataset.

### [Golden State Warriors Customer Analysis](./golden-state-warriors-customer-analysis)
**Texas A&M University · Data Engineering Coursework**  
**Python · pandas · scikit-learn · Classification · Regression**

Analyzed customer ticket-purchasing behavior and developed models to classify purchasing patterns and predict purchase timing. Compared KNN, logistic regression, and Random Forest approaches and used model evaluation and hyperparameter tuning to assess performance.

### [HPV Integration Site Prediction](./hpv-integration-site-prediction)
**BIG-TCR Summer Research Internship · McWilliams School of Biomedical Informatics · UTHealth Houston**  
**Python · TensorFlow · CNN · Genomics · Data Preprocessing · AlphaGenome**

Explored deep-learning approaches for predicting HPV viral integration sites as part of the Biomedical Informatics, Genomics and Translational Cancer Research Training Program (BIG-TCR). Developed a genomic preprocessing workflow and explored CNN models incorporating DNA sequence data and AlphaGenome-derived DNase/ATAC features.

### [Project LiAISon: Underwater Anomaly Detection](./liaison-underwater-anomaly-detection)
**Texas A&M University · Data Engineering Capstone**  
**Python · PyTorch · PointNet · Blender · Point Clouds · DBSCAN**

Developed an end-to-end workflow for detecting anomalies in synthetic underwater point-cloud scenes. The project included synthetic scene generation, simulated scanning, semantic labeling, point-cloud processing, clustering, and two-stage PointNet anomaly detection and classification.


Each project folder contains its own README with additional context, methodology, code, results, and supporting materials.
